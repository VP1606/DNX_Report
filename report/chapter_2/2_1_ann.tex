\section{Artificial Neural Networks \& Differentiability}
\label{sec:background_ann}

\glspl{ann} are a family of computational models that learn hierarchical feature representations by progressively mapping
input data through layers of weighted, non-linear transformations \cite{lecun2015deep}. 
Training an \gls{ann} relies entirely on minimising a loss function via gradient descent, where error signals are
propagated backward through the network using the chain rule of calculus (backpropagation). 

A fundamental, architectural constraint of this process is that every operation in the computational graph must be
continuous and differentiable; if a non-differentiable operation is encountered, the chain rule breaks down and the
gradient signal is zeroed.
This constraint is easily satisfied in standard \glspl{ann} by using continuous activation functions like \gls{relu},
which are differentiable almost everywhere. 
However, as will be established in Section~\ref{sec:background_snn}, this continuous requirement becomes the primary
mathematical obstacle when transitioning to the discrete, event-driven paradigm of \glspl{snn}.
